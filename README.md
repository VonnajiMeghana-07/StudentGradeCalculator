# Student Grade Calculator

## Description
Student Grade Calculator is a Java-based application that calculates the total marks, percentage, and grade of a student based on the marks entered for each subject.

## Features
- Accepts student name
- Accepts number of subjects
- Accepts marks for each subject
- Validates user input
- Calculates total marks
- Calculates percentage
- Determines grade automatically

## Java Concepts Used
- Variables
- Operators
- Control Statements
- Arrays
- Strings
- Methods
- Input Validation
- Scanner for user input

## Grade Criteria
- 90 and above: A+
- 80–89: A
- 70–79: B
- 60–69: C
- 50–59: D
- Below 50: F

## How to Run

Compile the program:

javac StudentGradeCalculator.java

Run the program:

java StudentGradeCalculator

## Output
The application displays the student's name, total marks, percentage, and grade.
